[步驟一]dailyBrokerTradeSummary.csv
	結算各卷商每日各股的交易總股數(net_vol)、總額(net_amt)、平均股價(avg_price)
	net_vol算法：Σ(buy - sell)
	net_amt算法：Σ((sell - buy)*price)
	avg_price算法：(net_amt/net_vol)*-1
	資料欄位：date,trader_id,stock_id,net_vol,net_amt,avg_price
	UniKey：trader_id + date + stock_id
	
[步驟二]overnightTradeList.csv
	1.在每筆資料後加上下一個交易日的日期(date2)、交易量(net_vol2)、交易額(net_amt2)、平均股價(avg_price2)，
	  ***如果在下一個交易日該卷商沒有交易該股的紀錄，net_vol2、net_amt2填入0，avg_price2填入NA
	2.將net_vol < 0的資料列刪除
	3.加入is_overnigth欄位，依據條件進行標註： 
		(net_vol + net_vol2) <= 0標註為1，其餘標註為2
	資料欄位：date,trader_id,stock_id,net_vol,net_amt,avg_price,date2,net_vol2,net_amt2,avg_price2,is_overnight

[步驟三]overnightTradeList_fragment.csv
	將is_overnight=2的資料進行拆分處理，規則：
	1.將net_vol的值改成net_vol2的相反數，net_amt重新計算=新net_amt*avg_price*-1，is_overnight改為1
	2.新增一筆資料，欄位值如下：
		a.date、trader_id、stock_id、avg_price、date2欄位照抄
		b.net_vol = 原本的net_vol和新net_vol的差值，net_amt = 此處net_vol*avg_price*-1
		c.net_vol2、net_amt2、is_overnight=0，avg_price2=NA
	資料欄位：
	date,trader_id,stock_id,net_vol,net_amt,avg_price,date2,net_vol2,net_amt2,avg_price2,is_overnight		

[步驟四]overnightTradeStats_byDay.csv
	以日期為單位結算各卷商的 沖銷率、沖銷報酬率、沖銷勝負，
	1.先計算沖銷部位總交易成本與總交易成本：
		沖銷部位總交易成本(overnight_net_amt)：該卷商該日is_overnight=1所有股票的net_amt總和
		總交易成本(total_net_amt)：該卷商該日所有股票的net_amt總和
	2.延伸計算：	
		沖銷率(overnight_close_rate)：overnight_net_amt/total_net_amt
		沖銷報酬率(overnight_close_return)：各net_vol*(avg_price2-avg_price)總和/overnight_net_amt
		沖銷勝負(overnight_close_result)：overnight_close_return > 0 為1， overnight_close_return <= 0 為0
	資料欄位：
	date,trader_id,overnight_net_amt,total_net_amt,overnight_close_rate,overnight_close_return,overnight_close_result
